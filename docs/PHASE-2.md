# Phase 2 — Native FT8 encoder and waveform

Phase 2 adds a pure Swift FT8 transmit path:

- CRC-protected 91-bit message construction
- systematic LDPC(174,91) encoding
- FT8 Costas blocks and Gray-mapped data tones
- continuous-phase Gaussian FSK synthesis
- 12.64-second signal generation
- optional centred padding to a 15-second FT8 slot
- mono 16-bit PCM WAV export

The tone-vector tests are fixed reference vectors generated by the original `ft8_lib` implementation, rather than by the Swift code.

## Example

```swift
import FT8Encoder

let tones = try FT8Encoder.encode(text: "CQ G0ABC IO91")
let samples = FT8Waveform.generate(
    tones: tones,
    configuration: .init(sampleRate: 12_000, baseFrequency: 1_000)
)
try FT8WAVEncoder.writePCM16(
    samples: samples,
    sampleRate: 12_000,
    to: outputURL
)
```
